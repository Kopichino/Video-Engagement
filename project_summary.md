## 2. Details of Custom Scripts in OUC-CGE

We have written three custom utility scripts to automate cross-validation and evaluation:

1.  **`generate_fold_splits.py`**:
    *   Scans `OUC-CGE-dataset` folders (`high`, `mid`, `low`).
    *   Validates each `.mp4` file using OpenCV to ignore corrupted files (if any).
    *   Applies a 5-fold stratified split to ensure classes are balanced across folds.
    *   Downsamples majority classes in the training folds so each class has exactly the same number of samples (avoiding model bias).
    *   Saves space-separated CSV files in `splits/fold_X/` matching the Kinetics dataset format required by SlowFast.

2.  **`run_5fold.py`**:
    *   The master automation runner.
    *   Loops through folds `0` to `4` (or target folds).
    *   Injects path overrides for the active fold's dataset splits and sets the respective output directory to `work_dirs/fold_X/`.
    *   Launches training programmatically using SlowFast's `train_net.py` API.
    *   Parses validation metrics from stdout logs at the end of each run to print a quick training summary.

3.  **`consolidate_metrics.py`**:
    *   Evaluates the final 5-fold performance.
    *   For each fold, loads the best saved model checkpoint and runs validation dataset inference.
    *   Computes exact **Accuracy**, **Macro-averaged F1-Score**, and **Quadratic Weighted Kappa (QWK)** using customized numpy implementations (avoiding dependency on scikit-learn).
    *   Generates a final text report saved at `work_dirs/5fold_summary.txt`.

## 3. Current Config & Training Status

*   **Model**: Slow R50 (ResNet-50 3D CNN, Kinetics pre-trained).
*   **Hyperparameters**:
    *   `BATCH_SIZE`: 8 (optimized to prevent Out-of-Memory on 8GB GPU).
    *   `MIXED_PRECISION`: True (FP16 enabled to use RTX 4060 Tensor Cores).
    *   `NUM_WORKERS`: 4 (optimized for Windows disk input/output limits).
    *   `WARMUP_EPOCHS`: 5.0 (reduced from 34.0 so model can learn during 35-epoch runs).
*   **Active Job**: A background terminal task is running:
    ```powershell
    python run_5fold.py --max-epochs 35 --eval-period 5 --checkpoint-period 5
    ```
